# Airport Authority Data Analysis Dashboard

## Overview
This project analyzes over 1 million airline flight records to identify operational trends, delays, cancellations, and performance bottlenecks. The goal is to transform raw aviation data into meaningful business insights using data analysis techniques and interactive visualizations.

A Power BI dashboard was developed to support decision-making by presenting key performance indicators (KPIs) related to airline operations.

## Objectives
- Analyze large-scale airline operational data  
- Identify trends in delays, cancellations, and flight performance  
- Clean and prepare raw data for analysis  
- Develop meaningful KPIs for operational insights  
- Build an interactive dashboard for business intelligence reporting  

## Tools & Technologies
- Power BI  
- Data Cleaning & Transformation  
- Data Visualization  

## Dataset
The dataset contains over 1 million records of airline operations, including:
- Flight delays  
- Cancellations  
- Airports and routes  
- Time-based performance data  
- Operational metrics  

## Data Preparation
- Cleaned and validated large-scale dataset for accuracy and consistency  
- Handled missing and inconsistent values  
- Transformed raw data into structured format suitable for analysis  
- Prepared data for dashboard visualization  

## Key Metrics (KPIs)
The dashboard includes key operational metrics such as:
- Total number of flights  
- Average delay duration  
- Cancellation rate  
- Ground processing time  
- Route and airport performance  
- Customer satisfaction indicators  

## Dashboard Features
- Interactive Power BI dashboard  
- Filters for airport, route, and time period  
- Line, bar, pie, and map visualizations  
- Drill-down analysis for deeper insights  
- KPI tracking for operational performance  

## Key Insights
- Identified major contributors to flight delays  
- Highlighted airports/routes with higher cancellation rates  
- Analyzed time-based patterns in operational performance  
- Provided insights for improving efficiency and scheduling
